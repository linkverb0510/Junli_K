# 军理刷题 📚

基于 React + TypeScript + Vite 的军理刷题网站，支持本地刷题、错题本、收藏等功能。

## ✨ 功能特点

- 📝 **多种题型**：单选题、多选题、填空题
- 📖 **章节练习**：按章节分类刷题
- 🎲 **随机刷题**：打散顺序，查漏补缺
- ❌ **错题本**：集中复习做错的题
- ⭐ **收藏功能**：标记重点题目
- ⌨️ **键盘快捷键**：高效刷题体验
- 💾 **本地存储**：进度自动保存，无需登录

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| `A B C D` | 选择选项 |
| `← →` | 上一题 / 下一题 |
| `Enter` | 提交答案 |
| `F` | 收藏题目 |
| `?` | 显示快捷键帮助 |

## 🚀 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 运行测试
npm test
```
